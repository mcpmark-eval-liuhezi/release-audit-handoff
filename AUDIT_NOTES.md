# Release Audit Handoff Notes

This repository is the single source of truth for the quarterly release audit handoff. Everything the incoming owner needs should be here (or linked from here) rather than in browser tabs or local memory.

## Handoff checklist

1. Check the release tags for this repository on the **Tags** page: https://github.com/mcpmark-eval-liuhezi/release-audit-handoff/tags — at handoff time no git tags exist yet, so this list is currently empty.
2. Review the open pull request "Add release audit handoff notes" and merge it once the notes look complete.
3. Track remaining work in the tracking issue "Release audit handoff checklist" and its two sub-issues:
   - Verify release tags
   - Draft the release notes summary
4. Confirm the default branch is `main` and that all future audit work branches off it.
5. Walk through this file with the outgoing owner on the handoff call and note anything still living only in their head.

## Background

- Quarterly release audit handoff, moving from the outgoing owner to a colleague.
- The workspace was created fresh so the incoming owner can pick everything up from a single link.
- Default branch: `main`. Working branch for these notes: `audit/notes`.
